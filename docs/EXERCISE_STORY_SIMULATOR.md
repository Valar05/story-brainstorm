# Exercise Story Simulator — Kinetic Compression through Choreography

## Mission

Use exercise as a simulation substrate for writing, choreography, and animation. This is not a fitness side project. Repetition strips away plot novelty so force paths, anticipation, timing, recovery, contact, object resistance, delegation, and wasted motion become visible. The results return directly to Story Brainstorm prose and animation judgment.

Primary story corpus remains the same four works already mined for kinetic compression:
- *Treasure Island*
- *Dracula*
- *The Woman in White*
- *Moby-Dick*

Primary motion reference remains the Jackie Chan door stipulation: mastery is visible when unnecessary acceleration, impact, rebound, correction, noise, and recovery are deleted.

## Source skill crosswalk

Motion Dungeon's existing skill mine already records the animation-relevant installed/remote skill families. This simulator uses them as analytical lenses, not as a new production pipeline.

### Direction / motion premise
- `direct-motion-graphics`: decide what stillness stores; assign camera, subject, environmental, optical, and editorial motion; reject ambient drift.
- `author-motion-graphics`: translate accepted timing/beat/layer authority into timed transforms.
- `review-motion-graphics`: cold full-speed, picture-only, audio-only, motion-scarcity, cardboard, and character-authority review.

Story return: every scene movement must have jurisdiction. If nothing changes because of a motion, remove it.

### Source motion / correspondence
- `rotoscoping`: preserve source timing, selected keys, anchor/camera/scale truth; do not invent smooth in-betweens that erase source mechanics.
- `track-grounded-motion`: detect and then human-review release, travel, landing, pivot, weight, and contact events; detectors are sensors, never authority.

Story return: prose should preserve event structure rather than smoothing an action into generic verbs.

### Contact / load path
- `animate-grounded-strikes`: visible sole seating, ground-to-limb force path, collision, prop causality, no unproven step/pivot.
- `animate-paired-contact`: character and contacted object are one coupled system through release; collision pair first; coupled force, occlusion, deformation, release.

Story return: contact is a state transition, not punctuation. The object and body inherit each other's consequences.

### Pose / keyframe economy
- `pose-is-god`: final-rig pose first, fixed/orthogonal cameras, silhouette judgment, weapon contract.
- `author-hexen-fps-melee`: choose semantic extrema rather than preserving every source frame; support/pelvis/contact readability and whole-library coherence.
- `author-fps-strike`: guard -> load -> approach -> contact -> consequence -> recall -> guard.

Story return: the key poses are not merely pretty endpoints; they are causal states. A prose beat should know its guard, load, contact, consequence, and recovery equivalents.

### Performance / speech
- `animate-lip-sync`: operative words, coarticulation, visible closure/contact/release, acting capture, no phoneme-slot-machine animation.

Story return: dialogue is choreography. Operative words should coincide with meaningful bodily or relational state changes rather than floating above them.

### 3D preservation / transfer
- `repair-3d-animation`: preserve accepted motion; repair only the bounded failing channel; reject unrelated mutation.
- `sprite-is-final`: freeze accepted animated authority before 2D transfer; calibration must not rewrite motion.
- `render-glb-locally` / `3d-site-is-god`: fixed-view evidence and motion frame pairs are diagnostic witnesses, not substitutes for human visual judgment.

Story return: revision should preserve what already works. Do not rewrite an entire scene because one load path, line, or transition fails.

### Cinematic / audiovisual causality
- `direct-cinematic-video`: one dramatic job per shot, motivated camera, pressure/release edit, collision-synced impact/mechanism/fallout/room.
- `mix-and-master-audio`: hierarchy and local ducking; metrics never prove sound identity or quality.

Story return: camera and sound should reveal or amplify causality already present in the action, not manufacture importance after the fact.

## Four-source exercise simulation

### 1. Treasure Island — Livesey / Billy Bones

Source event: Billy Bones draws a knife; Dr. Livesey does not retreat or escalate and continues calmly until Bones yields.

Exercise drill:
- Performer A spends visible threat: advance, weapon, breath, posture.
- Performer B is forbidden to add theatrical defense.
- Reduce B's response toward the minimum sufficient channels: gaze, voice, breath, tiny alignment changes.
- Repeat until every anticipatory twitch is exposed as either necessary or waste.

Skill cross-reference:
- `direct-motion-graphics`: stillness stores reserve.
- `track-grounded-motion`: distinguish actual weight shifts from ornamental acting.
- `pose-is-god`: silhouette must still read under near-zero motion.
- `review-motion-graphics`: motion-scarcity test asks whether removing another movement weakens or strengthens the beat.

Writing law:
**Motion contrast is characterization.** The threatening body spends uncertainty. The still body can imply reserve because pressure remains external and legible.

Animation law:
Stillness is not zero animation. Breath, balance, eye line, micro-settling, and the opponent's expenditure create the moving system.

### 2. Dracula — Harker / resistant architecture

Source event: Harker repeatedly discovers doors, hinges, locks, and spatial constraints whose mechanical state determines what his body must do.

Exercise drill:
- Use a mechanically specific resistance, not generic heaviness.
- Track force from contact -> grip -> wrist -> elbow -> shoulder -> trunk -> pelvis -> feet -> ground -> object -> hinge/floor/contact surface.
- Change one constraint at a time: hinge drag, handle height, floor friction, stance, direction of force.
- Remove fake strain that does not contribute to the load path.

Skill cross-reference:
- `animate-grounded-strikes`: ground-to-limb force path even when the action is not a strike.
- `animate-paired-contact`: body and door become one coupled system during effort.
- `track-grounded-motion`: pivot, weight transfer, release, recovery.
- `repair-3d-animation`: if the hand is right but the root floats, repair the root; do not replace the whole performance.

Writing law:
**Force should have an address.** "He struggled" is low information. A dropped hinge scraping the floor tells the reader exactly why the body changes.

Animation law:
The object's failure mode authors the choreography. Animate the resistance, then let the body answer it.

### 3. The Woman in White — Fosco / Madame Fosco

Source event: Madame Fosco catches Count Fosco's eye and acts. A tiny cue produces a large blocking change in another body.

Exercise drill:
- Performer A may use only one micro-cue: eye line, chin, finger, breath, pause.
- Performer B must perform the large state transition: leave, stop, hand over, redirect, sit, conceal.
- Shrink A's cue until clarity nearly fails; then restore the minimum necessary amount.
- Vary whether B anticipates the cue early, receives it on time, or checks for confirmation.

Skill cross-reference:
- `direct-motion-graphics`: assign motion jurisdiction across bodies.
- `animate-lip-sync`: operative cue timing and visible closure/contact/release apply even without speech.
- `animate-paired-contact`: social contact can be phase-coupled even without physical touch.
- `review-motion-graphics`: character-authority test—does B still appear autonomous, or merely puppeted?

Writing law:
**Causal motion can cross bodies.** The character who changes the scene need not perform the large movement.

Animation law:
The receiver's response is part of the sender's choreography. Command can be animated as a coupled two-body system.

### 4. Moby-Dick — Queequeg / harpoon

Source event: Queequeg demonstrates accuracy, then quietly hauls the line back in. Recovery confirms mastery as strongly as release.

Exercise drill:
- Perform one reaching, throwing, striking, or tool action.
- Score setup, load, release, contact/endpoint, residual imbalance, recovery steps, tool reacquisition, breath, and return to readiness.
- Repeat until success no longer requires exaggerated recovery.
- Then deliberately over-muscle the action and compare how much corrective motion appears.

Skill cross-reference:
- `author-fps-strike`: guard -> load -> approach -> contact -> consequence -> recall -> guard.
- `author-hexen-fps-melee`: semantic extrema rather than frame soup.
- `track-grounded-motion`: release/travel/landing/pivot/weight event map.
- `animate-grounded-strikes`: force path and contact readability.
- `review-motion-graphics`: full-speed watchdown; metrics do not prove convincing weight.

Writing law:
**Recovery proves the action.** Mastery is not just successful contact; it is how little debt remains afterward.

Animation law:
The final pose is not the end. The return to usable readiness is part of the causal sentence.

## Synthesis: kinetic compression as choreography

The four works and the Motion Dungeon skill corpus converge on the same first principles:

1. **Every motion has jurisdiction.** Camera, body, object, environment, sound, and another actor should not all move merely because motion is available.
2. **Pressure makes stillness legible.** Stillness without incoming force is a pose; stillness under force can be action.
3. **Force follows a load path.** Contact without origin, transmission, commitment, consequence, and recovery is decorative motion.
4. **Contact couples systems.** Body and object, attacker and target, commander and receiver become temporary causal units.
5. **Recovery is debt accounting.** Extra steps, rebounds, regrips, balance corrections, and repeated attempts expose inefficiency or uncertainty.
6. **Preparation stores motion.** A stance, grip, arrangement, trained habit, prop state, or earlier blocking choice can delete later movement.
7. **Micro-actions can own macro-effects.** A glance can move another body; a tiny shift can redirect a later chain.
8. **Semantic extrema beat frame soup.** Preserve guard/load/contact/consequence/recovery states before inventing transitions.
9. **Do not smooth away truth.** Rotoscoping, pose tracking, and repair doctrine all warn against invented in-betweens that erase source timing, contact, or imbalance.
10. **Human perception remains authority.** Hashes, pose detectors, drift metrics, and event maps can expose failures; they cannot certify convincing weight, menace, restraint, or mastery.

## Exercise-to-writing simulator protocol

For any source scene already in Story Brainstorm:

1. Identify one concrete action or coupled interaction.
2. Strip plot novelty by repeating it as an exercise drill.
3. Mark semantic states: guard/setup, load/anticipation, approach, contact/decision, consequence, recovery, residue.
4. Draw the load path or command path.
5. Identify corrective motion: rebounds, extra steps, repeated instructions, regrips, explanatory dialogue, camera rescue, redundant prose.
6. Remove one correction at a time while preserving causal honesty.
7. Test whether another body/object/environment can carry part of the causality.
8. Return the surviving structure to prose: write only the motions and details needed to expose the state transitions.
9. Return the same structure to animation: key semantic extrema first; breakdowns only where continuity actually requires them.
10. Review full-speed, picture-only, and where relevant audio-only. If the causal chain disappears without explanation, the compression failed.

## Standing Story Brainstorm question

**How much causal truth can the body carry before prose has to explain it?**

The animation mirror is:

**How little motion can we spend while preserving weight, intention, contact, consequence, and recovery?**

That is the exercise lane of kinetic compression.
